# Plan: 전투 이펙트와 다음 전투 확인

## Goal
카드 행동과 하수인 공격에 카드별 고유 이미지 이펙트를 연결하고, 전투 보상 이후에는 플레이어가 다음 전투로 진행할지 선택하게 한다. 다음 전투를 거절하면 현재 판을 보존하고 메인 메뉴로 돌아가 이어할 수 있게 한다.

## Architecture
- 이펙트 이벤트는 `apps/web/src/game`의 화면 세션 상태에서만 관리한다. `RunState`에 넣거나 API/Cosmos 저장 스키마를 바꾸지 않아 동작 중인 일회성 애니메이션이 저장 데이터에 남지 않게 한다.
- 이벤트는 행동을 수행한 카드의 ID, 공격/주문 효과 종류, 출발점, 도착점을 갖는다. 하수인 공격은 하수인 카드 ID, 주문은 주문 카드 ID를 사용한다. 카드 행동이 없는 적의 직접 영웅 공격에는 공통 피격 이펙트를 사용한다.
- 이미지 파일은 `/art/effects/{cardId}.png`로 제공한다. 카드 30종마다 어두운 판타지풍 투명 배경 이미지를 둔다. 공통 피격 이미지는 `/art/effects/impact.png`다.
- 다음 전투 확인은 보상 처리 후 현재 `battle.status === "playerWon"`인 화면을 대체한다. 진행 선택은 기존 `continue-run` 액션으로 전투를 시작하고, 메뉴 선택은 run 상태를 변경하지 않고 메뉴 화면으로 이동한다. 메뉴에서 이어하기를 누르면 같은 확인 화면이 다시 보인다.

## Scope Notes
- 기존 카드 그림, 게임 규칙, 적 행동, 승리 보상 규칙은 유지한다.
- 로컬 데모는 새로고침 후 run을 복원하지 않는다. 메뉴 안에서 나갔다 이어하기만 이 계획의 범위다.
- 이미지 제작과 애니메이션, 전투 확인 UI를 구현하고 빌드 및 브라우저 수동 확인을 수행한다.
