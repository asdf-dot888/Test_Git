# Decisions: 적 초반 전개 보정

- Date: 2026-10-26
- Status: Confirmed

## D01. 적 덱의 마나 비용 구성
- **Chosen**: 적의 성격별 카드 선택을 유지하면서 저비용 카드와 하수인이 초반에 충분히 나오도록 30장 덱의 비용 구성을 조정한다.
- **Rationale**: 적이 손에 있는 카드를 마나 부족으로 내지 못하거나 초반 필드가 비는 상황을 줄인다.

## D02. 적 시작 손패 보정
- **Chosen**: 적의 시작 손패 3장에 저비용 하수인을 최소 1장 보장한다. 기존 손패/덱의 크기를 늘리지 않고 무작위 시작 손패를 보정한다.
- **Rationale**: 적의 첫 전개가 빈 필드로 끝나는 상황을 직접 줄이면서, 매번 같은 손패를 주지 않는다.

## D03. 적 마나 회복
- **Chosen**: 적은 전투 시작 시 마나 5/10으로 시작하고, 적 턴 기준 1~3턴에는 1, 4~6턴에는 2, 7턴부터는 3을 회복한다. 사용하지 않은 마나는 유지하며 최대 10으로 제한한다.
- **Rationale**: 플레이어와 같은 성장 규칙을 적용해 후턴으로 인한 초반 전개 불리함을 줄인다.

## D04. 적 전용 마나 카드
- **Chosen**: 이번 초반 전개 보정에는 ‘마력의 샘’을 추가하지 않는다.
- **Rationale**: 비용 0 마나 카드가 무작위 손패에 잡히는 것만으로는 하수인 전개를 보장하지 못한다. 저비용 하수인 보장과 마나 비용 구성 조정이 빈 필드 문제에 더 직접적이다.

## 구현 참고
- 코드 확인 결과 적은 매 전투 30장 덱을 적 성격에 따라 가중 무작위로 구성하고, 시작 손패 3장을 받는다. 현재 적 마나는 첫 전투 시작 5/10이며 이후 턴마다 1만 회복한다.
- 플레이어 마나 회복은 플레이어 턴 기준 1~3턴 +1, 4~6턴 +2, 7턴 이후 +3이며 최대치는 10이다. 적에도 동일한 구간별 회복을 적용한다.
- ‘마력의 샘’ 카드는 현재 플레이어 전용이며, 적 덱 생성에서 제외된다. 이 상태를 유지한다.
- **구현 시 추론할 값**: ‘저비용’은 1~3 마나 하수인으로 해석한다. 덱의 구체적인 비용별 비율은 적 성격별 카드 가중치를 살펴 구현 계획에서 정한다.
- 기존 카드 풀, 적 체력/공격력, 일반·보스의 기존 성격별 행동 점수는 이번 범위에서 변경하지 않는다.
