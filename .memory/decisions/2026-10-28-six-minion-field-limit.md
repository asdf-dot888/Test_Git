# Decisions: Six Minions Per Field

- Date: 2026-10-28
- Status: Confirmed

## D01. Field capacity
- **Chosen**: Allow up to six minions on both the player's and enemy's fields.
- **Rationale**: Both sides should follow the same battlefield capacity.

## D02. What counts toward the limit
- **Chosen**: The six-minion limit applies to minions played from hand and minions created by card effects or hero powers.
- **Rationale**: Summoned minions occupy the same field slots as played minions, so all creation paths should use one shared limit.

## D03. Full-field behavior
- **Chosen**: Preserve the current behavior when a field is full; only change the capacity from five to six.
- **Rationale**: This request changes the field size, not how failed or excess summons are resolved.
