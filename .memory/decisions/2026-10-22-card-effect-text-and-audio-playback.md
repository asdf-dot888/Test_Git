# Decisions: 카드 효과 설명과 오디오 재생 문제

- Date: 2026-10-22
- Status: Confirmed

## D01. 카드 효과 설명
- **Chosen**: 모든 하수인과 주문 카드에 실제 게임 효과를 한국어로 구체적으로 표시한다. 전투의 함성·죽음의 메아리는 해당 용어와 대상/수량/수치를 표시하고, 주문은 피해·회복·강화·소환·드로우의 대상과 수치를 표시한다. 특별한 효과가 없는 하수인은 `특수 효과 없음`이라고 표시한다.
- **Rationale**: 사용자는 `전투 능력을 가진 하수인` 같은 포괄 문구 대신 카드별 효과를 정확히 알고 싶어 한다. 엔진의 효과 데이터와 카드 설명이 다르게 유지되지 않도록 설명은 실제 카탈로그 효과를 반영한다.

## D02. 배경 음악과 효과음이 재생되지 않는 문제
- **Chosen**: 기존 오디오 파일과 음량 설정은 유지하고 개발 모드에서도 오디오 컨트롤러가 정상 동작하도록 수명 주기 문제를 수정한다. React `StrictMode`를 제거하지 않는다.
- **Rationale**: 브라우저에서 음소거가 꺼져 있고 음량이 켜져 있는데도 소리가 나지 않는다고 사용자가 확인했다. 코드 탐색에서 개발 앱은 `StrictMode`로 렌더링되며, `GameSessionView` effect 정리가 state에 보관한 오디오 컨트롤러를 영구 폐기하는 경로를 확인했다. 정리 후 같은 인스턴스의 재사용을 막는 것이 무음 원인으로 보인다.

## Existing Constraints
- 카드 정의는 `packages/game-core/src/catalog.ts`에 수치화된 `minion.effect` 또는 `spellEffects`를 보관하고, 화면의 카드 설명은 동일 정의의 `description`을 렌더링한다.
- 배경 음악과 효과음 파일은 로컬 `public/audio/`에서 제공되고, 현재 개발 서버의 배경음 및 효과음 URL은 HTTP 200을 반환한다.
- 브라우저 자동 재생 정책 때문에 첫 사용자 입력에서 오디오를 활성화하는 흐름은 유지해야 한다.
- 수렁 마녀 설명을 카드별 문구로 바꾼 기존 로컬 변경이 있으므로, 후속 구현에서 전체 카드 설명 개선에 포함하고 중복 작성하지 않는다.

## Out of Scope
- 오디오 파일이나 효과음 종류를 새로 교체하지 않는다.
- 카드의 게임 수치나 실제 효과를 변경하지 않는다.
- 브라우저 자동 재생 제한을 우회하지 않는다.
