# Decisions: Game Title — Mangostone

- Date: 2026-10-28
- Status: Confirmed

## D01. Official game title
- **Chosen**: Use “망고스톤” as the Korean title and “MANGO STONE” as the English brand name, without a subtitle.
- **Rationale**: The title is memorable and matches the deployed site's existing Mango Stone name.

## D02. Product-facing title references
- **Chosen**: Replace the current “잿빛 원정” / “ASHEN EXPEDITION” branding in the game UI and player-facing project guide with the new Korean and English title. Keep unrelated technical package names unchanged.
- **Rationale**: Present one consistent title in the game and its accompanying architecture guide without renaming internal code identifiers.
