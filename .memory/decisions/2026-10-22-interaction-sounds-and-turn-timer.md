# Decisions: 상호작용 효과음과 턴 제한 시간

- Date: 2026-10-22
- Status: Confirmed

## D01. 입력 및 전투 효과음 범위
- **Chosen**: 모든 마우스/포인터 입력에 공통 UI 클릭음을 재생하고, 턴 시작·턴 종료·하수인 소환·공격·주문·회복·피해·사망 등 실제 동작에는 동작별 효과음도 재생한다. 관련 동작은 기존 효과음을 적절히 공유할 수 있다.
- **Rationale**: 카드 선택과 대상 지정 같은 입력에도 피드백을 주면서 게임 상황을 소리로 구분할 수 있다. 모든 동작에 별도 음원 파일을 만들 필요는 없다.

## D02. 효과음 자산과 음량
- **Chosen**: 게임 분위기에 맞는 절제된 금속 클릭음과 은은한 마법 종소리 경고음을 별도의 로컬 CC0 파일로 추가한다. 경고음은 일반 효과음 음량 설정의 40%로 재생하고 전체 음소거 설정을 따른다.
- **Rationale**: 기존 로컬 음원은 공격·피해·주문·회복·사망용이며 UI 클릭과 타이머 경고 역할의 파일은 없다. 새 파일도 로컬에서 재생해 런타임 네트워크 요청에 의존하지 않는다.
- **Asset references**: [Kenney Interface Sounds (CC0)](https://opengameart.org/content/interface-sounds), [UI Sound Effects: clicks and notifications (CC0)](https://opengameart.org/content/ui-sound-effects-button-clicks-user-feedback-notifications). 선택한 파일과 변환 내역은 기존 `apps/web/public/audio/ASSETS.md`에 기록한다.

## D03. 입력 장치
- **Chosen**: 게임 조작은 마우스/포인터 입력으로 한다. 키보드는 `Escape`만 허용한다. 메뉴 선택 화면에서는 `Escape`로 메뉴를 열고 닫으며, 설정 화면에서는 기존 메뉴 탐색 흐름에 따라 먼저 선택 화면으로 돌아간다. `Enter`, `Space`, 키보드 이동을 게임 조작에 사용하지 않는다.
- **Rationale**: 사용자가 마우스 중심 조작을 요청했고, `Escape`만 메뉴 전환 예외로 지정했다.

## D04. 턴 타이머 규칙
- **Chosen**: 플레이어의 각 전투 턴은 20초이며 새 플레이어 턴마다 20초로 초기화한다. 화면 상단 전투 헤더에서 `TURN N` 오른쪽에 `00:20` 형식으로 표시한다. 0초가 되면 자동으로 턴을 종료한다.
- **Rationale**: 제한 시간을 명확히 보여주고 입력이 없을 때 전투가 멈춰 있지 않도록 한다.

## D05. 타이머 일시 정지와 표시
- **Chosen**: 게임 메뉴가 열리거나 전투 효과 연출이 재생되거나 브라우저 탭이 숨겨진 동안 타이머를 멈추고 남은 시간을 보존한다. 전투 연출 중에는 타이머를 숨긴다. 메뉴가 열리면 기존 배경 흐림 처리만 적용하며 별도의 `일시 정지` 문구를 추가하지 않는다.
- **Rationale**: 플레이어가 실제로 행동할 수 없는 동안 시간을 소모하지 않으면서 기존 메뉴의 흐림 레이어와 시각 구성을 유지한다.

## D06. 시간 임박 경고
- **Chosen**: 5초 이하부터 `00:05` 등 타이머 글자를 빨갛게 깜빡이고, 5초부터 1초까지 매초 경고음을 재생한다. 경고음은 일반 효과음의 40% 음량으로 설정한다.
- **Rationale**: 남은 시간을 눈과 귀로 확인할 수 있게 하되 전투 효과음보다 경고음을 작게 유지한다.

## D07. 카드 및 전투 연출 속도
- **Chosen**: 공격과 주문의 이동 연출을 현재보다 약 1.5배 느리게 한다. 현재 620ms 이동 애니메이션은 약 930ms로, 충돌 연출까지 포함한 완료 시간은 대략 1.4초 수준으로 조정한다.
- **Rationale**: 카드 이미지와 공격 동작을 식별하기 쉽도록 충분한 재생 시간을 준다.

## D08. 타이머 저장 범위
- **Chosen**: 로그인 모드는 서버에 저장되는 기존 전투 진행과 함께 남은 시간을 저장해 새로고침 후 같은 턴을 이어간다. Local Demo는 현재 전투 진행을 저장하지 않으므로 새로고침하면 새 게임으로 시작한다. 데모 진행 저장 기능은 이번 작업에 추가하지 않는다.
- **Rationale**: 로그인 모드의 저장 동작과 일치시키며, 데모의 저장 범위를 임의로 넓히지 않는다.

## Codebase findings and scope notes
- `apps/web/src/game/combatEffects.ts`는 공격·주문·피해·회복·사망 효과음을 전투 이벤트에 연결하지만 일반 UI 입력음과 턴 시작음은 아직 연결하지 않는다.
- `apps/web/src/components/CombatEffectLayer.tsx`는 이동 애니메이션의 종료 시점에 효과 이벤트를 정리한다. 타이머는 남은 전투 효과 이벤트가 없어질 때 재개할 수 있다.
- Local Demo의 `useDemoRunSync`는 전투 진행을 저장하지 않는다. 로그인 모드의 `useRunSync`는 `RunState` 전체를 API에 저장한다.
- 현재 서버는 게임 상태 스냅샷을 저장한다. 만료된 턴 액션을 서버에서 강제로 차단하는 검증은 별도 작업 범위다.
- 키보드 조작을 `Escape` 메뉴 토글로 제한하면 Tab/Enter/Space를 통한 접근성이 줄어든다. 이는 사용자가 선택한 마우스 중심 조작에 따른 동작이며, 접근성 대체 입력은 이번 작업에 추가하지 않는다.
