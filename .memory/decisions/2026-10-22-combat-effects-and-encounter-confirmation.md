# Decisions: 전투 이펙트와 다음 전투 확인

- Date: 2026-10-22
- Status: Confirmed

## D01. 전투 이펙트 시각 스타일
- **Chosen**: 카드 플레이와 전투 행동에 이미지 기반 이펙트를 사용한다.
- **Rationale**: 사용자가 CSS 기본 연출보다 카드별 이미지 이펙트를 선택했다.

## D02. 카드별 이펙트 이미지
- **Chosen**: 기존 카드 일러스트와 별개로 카드마다 고유한 이펙트 이미지를 준비한다. 현재 카탈로그의 카드 30종을 기준으로 한다.
- **Rationale**: 사용자가 카드 30종마다 별도 이펙트 이미지를 새로 준비하는 방식을 선택했다.

## D03. 이펙트 애니메이션
- **Chosen**: 공격 또는 주문 이펙트 이미지는 대상 방향으로 짧게 이동하고, 타격 순간 효과를 보여준 뒤 사라진다.
- **Rationale**: 보드 중앙을 크게 덮거나 효과가 계속 남는 방식보다 짧은 대상 지정 연출을 선택했다.

## D04. 다음 전투 확인 시점
- **Chosen**: 판을 시작한 뒤 첫 전투는 바로 시작한다. 이후 각 전투 승리 보상을 선택하거나 건너뛴 뒤 다음 전투 여부를 확인한다. 마지막 보스 승리 뒤에는 다음 전투 확인을 표시하지 않는다.
- **Rationale**: 사용자는 첫 전투 확인은 생략하고, 보상 처리 후 다음 전투를 확인하는 흐름을 선택했다.

## D05. 다음 전투를 거절했을 때
- **Chosen**: 다음 전투를 시작하지 않고 메인 메뉴로 돌아간다. 진행 중인 판은 보존하여 사용자가 메뉴에서 이어할 수 있게 한다.
- **Rationale**: 사용자는 판을 포기하지 않고 나중에 이어하는 방식을 선택했다.

## Implementation notes
- 기존 결정 문서의 어두운 판타지 일러스트 스타일과 맞춘다.
- 카드 행동이 없는 적의 직접 영웅 공격에는 카드별 이펙트가 없으므로 공통 피격 연출을 적용한다.
- 로컬 데모의 현재 상태는 메모리에만 있으므로, 메뉴 이동 중에는 보존되지만 새로고침 후 복구는 별도 저장 기능이 없으면 지원되지 않는다.
